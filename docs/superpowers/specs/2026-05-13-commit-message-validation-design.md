# 提交信息规范性与重复检测功能设计

## 背景

用户希望增加对提交信息的规范性检查和重复检测功能，通过打标签的方式展示结果。

## 功能设计

### 1. 提交信息规范性检查

**检查规则：**
- 必须符合 `type: description` 格式（中文冒号 `：` 或英文冒号 `:` 都可以）
- `type` 必须在预定义列表中：`feat`, `fix`, `refactor`, `style`, `docs`, `test`, `chore`, `perf`, `ci`, `build`

**标签样式：**

| 状态 | 标签 | 说明 |
|------|------|------|
| 规范 | 绿色 `规范` | 符合格式要求 |
| 不规范 | 红色 `不规范` | 不符合格式要求 |

### 2. 重复检测算法

**采用 Jaccard 相似度 + 分词：**

```
相似度 = |交集| / |并集|
```

- 将提交信息分词（按中英文逗号、空格、标点分割）
- 计算两个提交信息的相似度
- 阈值设为 **0.7**（70% 相似度视为重复）

### 3. 数据结构

```javascript
{
  normStatus: 'pass' | 'fail',  // 规范性状态
  isDuplicate: boolean,         // 是否重复
  duplicateGroup: number | null // 重复组编号，用于标记哪些是重复的
}
```

### 4. 实现位置

- **主进程 (main.js)**：
  - 新增 `analyzeCommitMessage` 函数：检查规范性和检测重复
  - 在构建提交记录时调用该函数

- **渲染进程 (renderer.js)**：
  - 修改 `renderCommitTable` 显示新标签列
  - 新增标签样式

- **样式**：
  - `.norm-tag` - 规范性标签基础样式
  - `.norm-pass` - 绿色，规范通过
  - `.norm-fail` - 红色，规范失败
  - `.dup-tag` - 橙色，重复标记

### 5. 实现计划

1. 在 `main.js` 添加 `analyzeCommitMessage(message, allMessages, currentIndex)` 函数
2. 在所有构建提交记录的位置调用该函数
3. 在 `renderer.js` 添加标签渲染逻辑
4. 添加 CSS 样式

## 验收标准

- [ ] 提交信息符合规范时显示绿色 `规范` 标签
- [ ] 提交信息不符合规范时显示红色 `不规范` 标签
- [ ] 重复提交显示橙色 `重复` 标签
- [ ] 标签组合正确显示（如既不规范又重复）
