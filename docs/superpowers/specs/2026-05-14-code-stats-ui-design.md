# 代码统计工具 UI 改造设计

## 变更概述

| 变更 | 描述 |
|-----|------|
| 1 | 活跃天数格式改为 "15天" |
| 2 | 项目选择标签改造：全部仓库后面跟仓库名，hover 显示分支下拉 |
| 3 | 各项目代码量统计改为树形表格（Git模式） |
| 4 | 提交记录明细改为树形表格 |

## 变更 1：活跃天数格式

**位置**：`renderer.js` 中的 `activeDays` 显示

**当前**：
```javascript
document.getElementById('activeDays').textContent = activeDays.size;
```

**改造后**：
```javascript
document.getElementById('activeDays').textContent = activeDays.size + '天';
```

## 变更 2：项目选择标签（projectTabs）改造

### 全部仓库标签
- 当前：`全部仓库`
- 改造后：`全部仓库（仓库A | 仓库B | ...）` 或保持 `全部仓库`

### 单个仓库标签
- 鼠标移入（hover）显示分支下拉菜单
- 支持多选分支
- 选中分支后自动更新统计数据

### 交互方式
- hover 显示分支复选框列表
- 点击标签直接筛选该仓库（不需要展开面板）

## 变更 3：各项目代码量统计 → 树形表格（Git 模式）

### 表格结构

| 项目名称 | 提交次数 | 新增行 | 删除行 | 净增行 | feat | fix | 其他 |
|---------|---------|-------|-------|-------|------|-----|-----|
| ▼ 仓库A | ... | ... | ... | ... | ... | ... | ... |
| &nbsp;&nbsp;&nbsp;&nbsp;仓库A/main | ... | ... | ... | ... | ... | ... | ... |
| &nbsp;&nbsp;&nbsp;&nbsp;仓库A/feature-xxx | ... | ... | ... | ... | ... | ... | ... |
| ▼ 仓库B | ... | ... | ... | ... | ... | ... | ... |
| &nbsp;&nbsp;&nbsp;&nbsp;仓库B/develop | ... | ... | ... | ... | ... | ... | ... |

### 规则
- 父节点可展开/折叠（点击展开图标）
- 父节点显示所有分支的汇总数据
- 子节点显示各分支的详细数据
- 默认全部展开

### 数据来源
- 从 `queryResult.branchStats` 获取数据
- 按仓库分组，每仓库下包含多个分支

## 变更 4：提交记录明细 → 树形表格

### 表格结构

| 选择 | 项目 | 分支 | 版本号 | 日期 | 类型 | 提交信息 | 新增 | 删除 | 净增 | 状态 | 操作 |
|-----|------|------|-------|------|------|---------|-----|------|-----|------|-----|
| □ | ▼ 仓库A | - | - | - | - | - | ... | ... | ... | - | - |
| □ | &nbsp;&nbsp;&nbsp;&nbsp;仓库A/main | main | r123 | 2026-05-10 | feat | 提交信息 | +50 | -10 | +40 | 正常 | 查看 |
| □ | &nbsp;&nbsp;&nbsp;&nbsp;仓库A/feature | feature | r124 | 2026-05-11 | fix | 提交信息 | +30 | -5 | +25 | 正常 | 查看 |

### 规则
- 增加「分支」列
- 项目名列：父节点显示仓库名（带展开图标），子节点为空或显示分支名
- 项目名前面的 `[Git]` 标签去掉
- 提交信息前面的 `[Git]` 标签去掉
- 按仓库+分支排序
